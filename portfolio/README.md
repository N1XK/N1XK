# N1XK Portfolio

A responsive dark-and-gold portfolio landing page linking to the seven N1XK projects.

## Publish
Upload the contents of this `n1xk-portfolio` folder to a folder named `portfolio` in the `N1XK/N1XK` repository. With GitHub Pages already enabled, the page will be available at:

`https://n1xk.github.io/N1XK/portfolio/`

Project cards link to sibling project folders in the repository.

Note: The portfolio assumes the project folders use these names: `n1xk-ai-dashboard`, `n1xk-analytics-pro`, `n1xk-security-ops`, `portfolio-website`, `quiz-app`, and `todo-list-app`. WeatherNow links to the repository root.
